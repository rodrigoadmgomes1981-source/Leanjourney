# Lean Journey | React + Vite

Sistema responsivo para mapeamento Lean da jornada do paciente em Pronto Atendimento.

## Rodar localmente

```bash
npm install
npm run dev
```

## Gerar build de produção

```bash
npm run build
```

A pasta `dist` gerada pode ser publicada na Vercel, Netlify ou Cloudflare Pages.
